# Chain of Command — Legal OS Interactive Prototype

Stitch design exploration for the Legal Operating System UI.

## Screens
- Design System
- Command Center
- The Docket
- Chambers (AI counsel team)
- Law Library
- Record Room
- Case Timeline / Chronology

## How to view
Open `/prototypes/legal-os/` (static) or open `index.html` locally.

Uses React 18 + Babel standalone for zero-build preview.
