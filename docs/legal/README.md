## Recommended next steps (low/no cost)

1. Add copyright headers to source files referencing the Apache-2.0 license.
2. Require every contributor or contractor to sign `IP_ASSIGNMENT.md` **before** they push code.
3. Use `NDA.md` before sharing private repositories or sensitive architecture.
4. Link TERMS.md and PRIVACY.md from the app UI / footer when the Service is public.
5. When budget allows, register the core codebase with the U.S. Copyright Office (~$45 electronic single-author filing).
